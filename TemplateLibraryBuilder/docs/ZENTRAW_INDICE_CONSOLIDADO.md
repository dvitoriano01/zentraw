## ❌ **VIOLAÇÕES CRÍTICAS - NEVER DO**

### 🚫 **PROIBIÇÕES ABSOLUTAS**

1. **Trabalhar sobre versão não-commitada** sem autorização
2. **Avançar versão automaticamente** sem consulta ao DEV
3. **Modificar código inteiro** sem rollback autorizado
4. **Quebrar sistema de 44 fontes** Freepik
5. **Ignorar protocolo de autorização**

### ⚠️ **EXCEÇÕES PERMITIDAS**

1. **Rollback total**: Com autorização expressa do DEV
2. **Consulta para melhorias**: Sempre permitida
3. **Trabalho sobre versão anterior**: Apenas para rollback autorizado
